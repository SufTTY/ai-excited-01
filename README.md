# ai-excited-01

A procedurally drawn supermassive black hole with a blazing accretion ring and a tiny spacecraft streaking past — one deterministic PNG written by a stdlib-only Python program, entered in make.fun's "Make the AI judge excited" bounty.

## Run it

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 -P -s main.py
```
